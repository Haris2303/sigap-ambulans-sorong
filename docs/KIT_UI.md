# KIT UI — SIGAP Ambulans v2 (Material Design 3)

> Pasangan `DESIGN.md` (identitas visual, token, larangan gaya). Dokumen ini menjawab "bagaimana dibangun di kode": tumpukan, kelas yang tersedia, komponen Blade, pola halaman. Tujuan: **semua halaman terasa satu aplikasi**. Halaman hanya merakit komponen; gaya tidak pernah ditulis per halaman. Sesi agen otonom tidak boleh mengubah dokumen ini; sesi interaktif boleh, bersama `DESIGN.md`.
>
> **Retema B "Terang lembut" (`docs/RETEMA_B.md`) mengalahkan dokumen ini dan `docs/DESAIN_DASBOR_MATERIAL.md` bila bertentangan.** Langkah R1 sudah mengganti token (warna, tipografi, bentuk, elevasi), font, dan aturan pemindai (§1 dan §9 di bawah sudah mengikutinya). Layout, komponen, dan halaman di §2 sampai §10 masih tampilan dasbor Material sampai dialihkan di R2 sampai R8; rencana komponen arah B ada di §11.
>
> **Arah dasbor Material (keputusan pemilik proyek, `docs/DESAIN_DASBOR_MATERIAL.md`) mengalahkan aturan Don't dan Layout lama, dan seluruhnya sudah dibangun (D1 sampai D7).** Komponen pra-dasbor `ringkasan`, `ringkasan-sel`, dan `grafik-batang` sudah dihapus; aturan `komponen-lama` mencegahnya kembali. Satu-satunya yang masih menunggu keputusan pemilik proyek: halaman Masyarakat tanpa laci navigasi (lihat akhir dokumen).
>
> **Material 3.** Token, aturan konsistensi, komponen, layout, dan halaman sudah Material 3. Nama token atau kelas lama ditolak oleh aturan `token-lama` di `agent/konsistensi.json` (pesannya memuat padanan baru). Catatan keputusan dan langkah migrasi ada di `docs/MIGRASI_M3.md`.

## 1. Tumpukan dan aset

| Hal | Ketentuan |
|---|---|
| CSS | Tailwind CSS 4.3 lewat Vite (`@tailwindcss/vite`). Token berasal dari `DESIGN.md`; `node agent/tokens.mjs` menghasilkan `resources/css/design-tokens.css` (jangan diubah dengan tangan). `resources/css/app.css` memuat dasar (latar, fokus, seleksi). CSS tambahan hanya di `resources/css/tambahan.css` (aturan di berkasnya; warna hanya `var(--color-…)`) |
| Font | Plus Jakarta Sans Variable dari paket npm (`@fontsource-variable/plus-jakarta-sans`, bobot 200 sampai 800), diimpor di `app.css`; `--font-sans` dihasilkan dari `DESIGN.md`. Impor Roboto (`@fontsource-variable/roboto`) masih ada tetapi tidak dipakai lagi, dihapus di R9. Tidak ada font dari internet |
| Ikon | Lucide, disalin ke `resources/icons/*.svg` (daftar di §6), ditampilkan lewat `<x-ui.ikon>` |
| JS | Vite: `resources/js/app.js` (impor `sigap.js`) dan `resources/js/peta.js` (Leaflet 1.9.4 + Leaflet Routing Machine 3.2.12 dari npm). Tidak ada CDN, tidak ada `<script src>` di view mana pun |
| Pemuatan | Hanya `layouts.dasar` yang memuat aset: `@vite(['resources/css/app.css','resources/js/app.js'])`, dan `@vite('resources/js/peta.js')` bila `:peta="true"` |
| Build | `npm run build` harus lulus. Tes memakai `$this->withoutVite()` (di `Tests\TestCase`) sehingga tidak perlu manifest |

**Kelas yang ada** (selain utilitas Tailwind biasa untuk tata letak: `flex`, `grid`, `gap-*`, `p-*`, `m-*`, `w-*`, `size-*`, `hidden`, `md:`, `lg:`, `truncate`, dst. dengan skala numerik bawaan):
- Warna: `bg|text|border|outline|ring|fill|stroke|divide-<token>` dengan token arah B `primary`, `on-primary`, `primary-container`, `on-primary-container`, `secondary`, `on-secondary`, `secondary-container`, `on-secondary-container`, `tertiary`, `on-tertiary`, `tertiary-container`, `on-tertiary-container`, `success`, `on-success`, `success-container`, `on-success-container`, `warning`, `on-warning`, `warning-container`, `on-warning-container`, `error`, `on-error`, `error-container`, `on-error-container`, `surface`, `surface-container-lowest`, `surface-container-low`, `surface-container`, `surface-container-high`, `surface-container-highest`, `on-surface`, `on-surface-variant`, `outline`, `outline-variant`, `inverse-surface`, `inverse-on-surface`, `inverse-primary`, `selected`, `scrim`, `chart-mint`, `chart-coral`, `chart-amber`, `chart-slate`, serta token lama `canvas` (sama dengan `surface`) dan `chart-sky` (grafik dasbor Material), keduanya dihapus di R9. Pengubah opasitas hanya untuk lapisan keadaan dan nonaktif (`/8`, `/10`, `/12`, `/38`, mis. `hover:bg-primary/8`, `disabled:text-on-surface/38`) dan pemakaian arah B: `bg-scrim/45` (scrim dialog dan laci), `bg-primary/25` dan `bg-primary/15` (lingkaran kartu navy), `bg-on-secondary/15` (chip ikon kartu navy), `ring-primary/20` (fokus isian).
- Teks: satu kelas per gaya, mengatur ukuran, tinggi baris, bobot, dan jarak huruf sekaligus. Arah B: `text-stat-hero` (56px), `text-stat-l` (38px), `text-page-title` (30px), `text-page-title-s` (26px), `text-title-xl` (22px), `text-title-l` (18px), `text-title-m` (16px), `text-brand` (19px), `text-ring-value` (16px), `text-body-l|m|s` (16, 14, 13px), `text-label-l|m` (14 dan 12px, bobot 600), `text-chip` (12px, bobot 700); nilai lengkap di `DESIGN.md` bagian Typography. Gaya lama (dihapus di R9 bila tak terpakai): `text-display-l|m|s`, `text-headline-l|m|s`, `text-title-s`, `text-label-s`, `text-card-title`, `text-stat-m`. Bobot hanya dari gaya; `font-normal|font-medium` masih ada untuk komponen lama dan dialihkan di R2 sampai R8. Angka berderet: `tabular-nums`.
- Sudut: `rounded-sm` (10px), `rounded-md` (14px), `rounded-lg` (18px), `rounded-xl` (24px), `rounded-2xl` (28px), `rounded-full`, `rounded-none`, serta `rounded-xs` (4px, lama, dihapus di R9).
- Bayangan (tinta biru tua `rgb(30 41 100)`): `shadow-card` (kartu, panel, bilah samping, kartu navy), `shadow-control` (kontrol melayang), `shadow-chip` (segmen aktif tab), `shadow-overlay` (dialog, menu tarik, laci ponsel, snackbar); `shadow-none` untuk yang datar. Lama, dipertahankan sampai pemakaiannya dialihkan dan dihapus di R9: `shadow-level-1|2|3`, `shadow-card-raised`, `shadow-nav-active`.
- Ukuran: `min-h-touch`/`h-touch` (48px), `w-drawer` (280px, kerangka lama sampai R3), `max-w-content` (1152px, kerangka lama sampai R3), `max-w-prose`.
- Gerak: `transition-colors` dan `transition-opacity` memakai 150ms dengan easing standar M3 secara bawaan; buka dan tutup (dialog, laci, scrim) 200ms (`--motion-duration-medium`).
- Kelas di `tambahan.css`: `gulir-tipis` (bilah gulir tipis `outline-variant` untuk daftar yang bisa bergulir, mis. menu laci), `lapisan-keadaan` (lapisan hover 8%, fokus 10%, tekan 10% berwarna `currentColor` di bawah isi kontrol) dan `target-sentuh` (memperluas area sentuh tak terlihat menjadi minimal 48px).

**Tidak ada** (tidak menghasilkan CSS, dan dipindai): palet bawaan (`bg-red-500`, `text-gray-600`, `text-white`), ukuran teks mentah `text-xs|sm|base|lg|xl…` dan `text-[13px]` (aturan `teks-mentah`), kelas bobot `font-thin|extralight|light|semibold|bold|extrabold|black`, `font-<angka>`, `font-[…]`, `rounded-3xl+`, `shadow-xs…2xl` dan bayangan lain di luar token (termasuk bayangan berwarna atau beropasitas seperti `shadow-primary/40`), `blur`, `tracking-*`, `uppercase`, `italic`, gradien, `animate-pulse|bounce|ping`, `hover:scale|translate`, nilai sembarang untuk `rounded` dan `shadow`. Boleh: `animate-spin` untuk indikator memuat.

## 3. Layout (`resources/views/components/layouts/`)

| Komponen | Dipakai oleh | Isi |
|---|---|---|
| `layouts.dasar` | dasar semua layout | `<html lang="id">`/`<head>`/`<body>`; judul `"{judul} - SIGAP Ambulans"`; `@vite` (lihat §1); `@stack('skrip')`; tautan "Lewati ke isi" untuk papan ketik. **Satu-satunya** tempat tag `<html>/<head>/<body>` dan `@vite` |
| `layouts.publik` | halaman tanpa login (landing, `/faskes`) | bilah atas kartu melayang (`Tampilan::KARTU`, tinggi 64px) di dalam `max-w-content` dengan `px-4 lg:px-7`: nama aplikasi di kiri; Info Faskes (hantu) dan Masuk (sekunder) di kanan, atau "Ke dasbor" bila sudah masuk; kaki halaman satu baris (nama Dinkes) |
| `layouts.auth` | login, register | kolom tunggal rata kiri, lebar maks 24rem, nama aplikasi di atas, isi dalam `panel`, tanpa panel dekoratif |
| `layouts.app` | semua halaman setelah login | **Laci** (`data-menu-rel`): putih (`bg-surface-container-lowest`), `lg+` tetap `w-drawer` (280px) `sticky top-0 h-screen` dengan tepi kanan 1px `surface-container-high`; di bawah `lg` laci modal `w-80` (maks. lebar layar dikurangi 56px) dengan `rounded-r-lg`, `shadow-level-1`, dan scrim `data-menu-scrim`, ditutup dengan tombol Tutup, klik scrim, atau Escape (`sigap.js`). Laci itu sendiri `overflow-y-auto gulir-tipis`; menu tidak punya bilah gulir lagi, sehingga hanya ada satu bilah vertikal per halaman. Kepala: tanda merek 40px (`primary`, `rounded-md`, ikon `plus`) dan nama aplikasi `text-title-l`. Menu dari `config('sigap.menu.<peran>')` dengan label grup (kunci `grup`), item pil 48px, hitungan dari View Composer (tanpa query di Blade). Dasar laci: blok pengguna (`bg-surface-container-low rounded-lg`) berisi avatar, nama, peran, dan tombol keluar ikon 20px (form POST ber-CSRF, bukan tautan). **Bilah atas** (`data-bilah-atas`): kartu melayang 64px (`Tampilan::KARTU`) di dalam pembungkus `sticky top-0 bg-canvas` di semua ukuran layar: tombol menu (hanya di bawah `lg`), kolom cari `x-ui.cari` (maks. 460px di `lg`; hanya untuk peran di `config('sigap.bilah_atas.cari')`), lonceng pesanan menunggu verifikasi (hanya Dinkes, `config('sigap.bilah_atas.lonceng')`; tautan ke daftar pesanan tab "Perlu tindakan"; `aria-label` "Pesanan menunggu verifikasi, {n}" diperbarui oleh `sigap.js`), dan avatar (di `lg` disertai nama dan peran dua baris). **Isi**: `min-w-0`, padding `px-4 lg:px-7`, `max-w-content`. Latar halaman `canvas` (dari `app.css`) |

## 5. Pola halaman

- **Daftar**: `judul-halaman` → filter dalam `panel` (isian dan pilihan, tombol "Terapkan", tautan "Atur ulang"; kata kunci `?q=` datang dari kolom cari di bilah atas dan dipertahankan lewat input tersembunyi) → `panel flush` berisi `tabs` (`?tab=`, `TabPesanan`) dan `tabel :bingkai="false"` → `paginasi` di luar kartu. Tanpa data: paragraf keadaan kosong di dalam kartu ("Belum ada pesanan di tab ini."). Ponsel: kolom sekunder `hidden md:table-cell`, tabel bergulir di dalam kartunya (`lebar-min`); baris dapat diklik penuh lewat kolom pertama berupa tautan.
- **Formulir**: satu `panel` lebar maksimum `max-w-xl`, kolom vertikal `space-y-5`; di dasar: `tombol utama "Simpan"` + `tombol hantu "Batal"`.
- **Detail**: dua kolom pada `lg` (kiri: `rincian` + `linimasa`; kanan: `panel` aksi), satu kolom di ponsel. Aksi hanya yang valid untuk status dan peran saat ini (`PesananStatus::transisiTerbuka()` + peran). Panel aksi **tidak boleh berada di dasar halaman ponsel**: letakkan di DOM tepat setelah data yang menentukan keputusan (untuk Dinkes: Pemohon dan pasien, lalu Lokasi jemput, lalu `div#aksi`, baru bagian lain), supaya urutan fokus papan ketik sama dengan urutan visual. Di `lg` kolom aksi memakai `lg:col-start-3 lg:row-start-1 lg:row-span-5 lg:self-start` pada grid `lg:grid-cols-3 lg:grid-rows-[auto_auto_auto_auto_1fr]`, dan tiap bagian kiri `lg:col-span-2 lg:col-start-1` (baris kelima fleksibel menampung tinggi lebih kolom aksi). Acuan: `admin/pesanan/show.blade.php`.
- **Aksi berbahaya** (tolak, batalkan, lepas): `tombol nada="bahaya"` dengan `konfirmasi`; alasan lewat `area-teks` pada form kecil bila aturan status menuntutnya.
- **Dasbor**: baris `stat` → baris `panel` berisi grafik, petak, atau tabel (acuan: Dasbor Dinkes, §10). Kartu statistik dan kartu data diizinkan; tidak ada kisi kartu fitur.
- **Landing (`beranda`)**: rata kiri, `max-w-prose`. H1 faktual: "Pesan ambulans Dinas Kesehatan Kota Sorong." Satu paragraf (apa yang dilayani, siapa yang memverifikasi). `tombol utama "Pesan ambulans"` + `tombol sekunder "Info Faskes"`. Bagian "Cara kerja": **daftar bernomor** empat langkah (pesan, Dinkes memverifikasi, ambulans dan sopir ditugaskan, pantau perjalanan) karena urutannya nyata. Tanpa gambar, ilustrasi, hero, atau kisi fitur.
- **Buat Pesanan (ponsel dulu)**: satu kolom; urutan: jenis layanan (`opsi-baris`), tingkat darurat, lokasi jemput (tombol besar "Gunakan lokasi saya" + peta + alamat), Faskes tujuan, data pasien, catatan; tombol "Tinjau pesanan" tetap terlihat di dasar layar ponsel (`sticky bottom-0 bg-surface-container p-4 shadow-level-1`).
- **Judul** = kalimat biasa (huruf awal kapital saja). Satu `judul-halaman` per halaman.

## 7. JavaScript

`resources/js/waktu-tunggu.js` (dipasang `sigap.js`): menghitung ulang lencana `waktu-tunggu` tiap 30 detik dan saat tab kembali tampil; aturan teks dan nada sama dengan `App\Support\WaktuTunggu`, ubah bersamaan.

`resources/js/formulir.js` (dipasang `sigap.js` untuk semua halaman): penjaga kirim formulir. Saat `submit`, tombol `type="submit"` formulir itu (termasuk yang memakai `form="id"`) dinonaktifkan dan labelnya diganti `data-memuat` (prop `memuat` pada `x-ui.tombol`; bawaan "Memproses..."), formulir diberi `aria-busy`, kiriman kedua dicegah, dan `pageshow` yang dipulihkan dari riwayat mengembalikan tombol. Tanpa spinner. Satu halaman tidak boleh memasang penanganan kirim sendiri.

`resources/js/sigap.js` (diimpor `app.js`): `Sigap.polling(url, detik, fn)`, `Sigap.notifikasi(judul, isi)`, `Sigap.lokasiSaya(fn)`, penanganan `data-konfirmasi` (membuka `ui.dialog`), menu laci, penutup snackbar, dan angka hidup Dinkes (`[data-ringkasan]`, `[data-lencana]`, label `[data-lonceng]`). Halaman boleh memakai `@push('skrip')` ≤ 20 baris yang **memanggil** helper itu; URL selalu dari `route()` dan dioper lewat atribut `data-*`; tidak ada `fetch` ke URL ketikan tangan; tidak ada pustaka JS lain.
`resources/js/peta.js`: `import L from 'leaflet'; import 'leaflet/dist/leaflet.css'; import 'leaflet-routing-machine'; import 'leaflet-routing-machine/dist/leaflet-routing-machine.css';` dan perbaikan ikon penanda bawaan Leaflet untuk bundler (`import iconUrl from 'leaflet/dist/images/marker-icon.png'` … lalu `L.Icon.Default.mergeOptions({ iconUrl, iconRetinaUrl, shadowUrl })`). Ubin peta OpenStreetMap, pencarian Nominatim, dan rute OSRM demo adalah satu-satunya permintaan jaringan eksternal; catat di `ASUMSI_DAN_KEPUTUSAN.md`.

### Contoh pemakaian grafik

```blade

    <h2 class="text-card-title">Pesanan 7 hari terakhir</h2>
```

Grafik digambar Chart.js (D3b), bukan SVG. Paket `chart.js` didaftarkan modular di `resources/js/grafik.js` dan dimuat `app.js` sebagai chunk terpisah hanya bila halaman punya `canvas[data-grafik]`. Warna, huruf, dan sudut dibaca dari variabel CSS token di runtime (tanpa hex di JavaScript; aturan `warna-js`), karena itu `design-tokens.css` memakai `@theme static`. Urutan, penyaringan, persentase donat, dan `max` batang dihitung di Blade dan diuji `KomponenGrafikTest`; `GrafikChartJsTest` menjaga impor, pemuatan dinamis, dan nama token. Gambar kanvas, tooltip, dan perubahan ukuran tidak teruji secara visual tanpa browser; yang diperiksa hanya konfigurasi (dijalankan sekali di Node dengan kanvas tiruan) dan HTML yang dihasilkan. Penyimpangan dari teks dokumen arah: celah donat dan radius batang pendek ditangani Chart.js sendiri (`spacing` dan batas radius), bukan hitungan manual.
